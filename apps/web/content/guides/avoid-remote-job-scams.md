远程工作因为跨地域、线上签约和美元高薪的吸引力，一直是虚假招聘和针对程序员定向攻击的高发区。过去两年里，甚至出现了专门针对开发者本机环境、借“远程技术面试”之名窃取钱包私钥和浏览器 Cookie 的高度伪装团伙。

无论你是找全职还是接兼职，在投递、下载测试代码和签署协议前，务必把下面这五类常见骗局和排查清单记牢。

## 一、最高危骗局：假借“远程面试”发恶意代码仓库（尤其高发于 Web3/AI）

这是近两年针对全球远程开发者（尤其是全栈、前端、区块链工程师）破坏力最大的一类攻击：
- **典型套路**：对方自称某知名 Web3 / AI / 金融科技创业公司 Recruiter 或 CTO，通过 LinkedIn、Telegram 或社区私信联系你，开出诱人薪资（如 $120K–$180K），寒暄几句后立刻发来一个 Bitbucket / GitHub / GitLab 私有测试仓库或压缩包，让你 `npm install && npm start` 在本地跑起来改个小功能。
- **隐藏陷阱**：恶意代码藏在 `package.json` 的 `postinstall` 脚本、混淆过的配置文件、假 `.env` 加载器或某个深层依赖文件里。只要你在主力开发机上运行了安装或启动命令，脚本就会静默扫描你的浏览器扩展数据（MetaMask 等钱包）、SSH 密钥、`.env` 环境变量和本地凭据并回传攻击者服务器。
- **防范铁律**：
  1. **永远不要在日常主力电脑宿主机直接运行陌生招聘方发来的代码仓库**；
  2. 先在网页端通读 `package.json`（特别看 `scripts` 和奇怪的依赖）、`Makefile`、配置文件及所有非标准混淆代码；
  3. 确实需要运行面试项目时，使用**无任何个人账号/密钥/钱包的隔离环境**（如 GitHub Codespaces、一次性 Docker 容器或干净的虚拟机）。

## 二、以“面试测试题 / 试稿”为名的免费白嫖外包

- **典型套路**：部分不良外包中介或小团队把真实的客户生产需求拆分成“面试实战题”，要求候选人免费花 3–5 天开发完整页面、爬虫或后端接口并提交源码，收完代码后直接失联或以“不合适”敷衍。
- **识别信号**：
  - 还没见过技术面试官、连 15 分钟语音都没聊过，上来就发一个庞大且高度贴近某个具体商业产品的开发任务；
  - 要求你把完整源码提交到对方的私有仓库或直接部署到对方的测试服务器；
  - 预计工作量远超正常 Take-home 范围（正规远程公司的免费笔试一般控制在 2–4 小时内；超过半天的深度试做通常会支付试工费 Paid Trial）。
- **防范铁律**：先面再做、控制投入时间；超过 4 小时的真实业务开发要求，礼貌提出改为付费试工（Paid Trial Project）并明确结算单价。

## 三、要求预先付费、押金、买设备或“培训转正”

- **典型套路**：
  - 声称入职前需缴纳“工牌/VPN 开通费/背景调查费/保证金”；
  - 发来一张伪造的支票或转账截图，让你先自掏腰包向所谓“指定供应商”购买指定型号的 MacBook；
  - 招聘贴写着高薪远程，加上微信后话锋一转推销几千到上万元的“远程技能保过培训班/接单训练营”。
- **防范铁律**：**任何正规远程雇主在任何环节都不会向求职者收取一分钱**。遇到“先交钱再入职/先买课再派单”，立刻拉黑并向发布平台举报。

## 四、伪装成海外开发岗的灰色/黑产与洗钱陷阱

- **典型套路**：
  - 招聘需求语焉不详，但强调“急招、高薪日结、不看学历、只需要用你的实名账号注册云服务/收款账户/协助转发资金”；
  - 开发内容涉及博彩、诈骗盘口、未经授权的木马/窃密插件或伪造合规应用上架。
- **防范铁律**：切勿出租或借出个人银行卡、支付宝、海外收款账户、实名云服务器或苹果/谷歌开发者账号；对业务模式含糊不清、拒绝展示真实产品官网的项目保持高度警惕。

## 五、画大饼的“纯期权 / 零底薪合伙人”与空头支票

- **典型套路**：宣称项目马上拿大额融资，前期零工资或极低生活费，许诺上线后给 5%–15% 股权，但既无清晰公司主体、也无正式股东协议与成熟商业验证。
- **防范铁律**：除非你本身就是出于共同创业意愿且对合伙人知根知底，否则**不要拿“口头期权承诺”替代合理现金报酬**；远程兼职/外包坚持“先签书面协议 + 收取首付款（如 30%–50%）再启动编码”。

## 六、3 分钟公司背景尽调清单（投递与面试前必查）

每次准备深入沟通或接受面试作业前，花 3 分钟做完这 5 步检查：

1. **查域名与邮箱**：正规公司发面试邀请通常使用企业官方域名邮箱（如 `name@company.com`），如果自称大厂或融资公司却只用免费 Gmail / QQ 邮箱且官网域名刚注册几天，高度可疑；
2. **查领英与核心成员**：在 LinkedIn 搜索公司名与面试官姓名，看公司是否真实存在多名员工、过往经历是否连贯；
3. **查产品与公开痕迹**：搜公司官网、GitHub Organization、Product Hunt、Crunchbase 融资信息或社区评价；
4. **核对沟通渠道**：全程只肯在 Telegram 上用匿名小号文字沟通、拒绝露脸视频面试或拒绝说明公司法定注册主体的岗位，风险极高；
5. **在 RemoteCN 发现可疑职位随时反馈**：虽然我们已尽力过滤异常招聘，但如果遇到要求预先付费、索要敏感证件照片或发送可疑代码的职位，欢迎通过 [联系我们](/contact) 告知，我们会第一时间核实下架。
